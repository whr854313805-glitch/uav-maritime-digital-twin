## 接收人怎样复跑

按 [README 命令](../../README.md#检查与重算)串行执行：环境检查 → 52测试 → 9基础 → M2/相向重算。每条退出码应为0；测试应为 `OK`，数据/重算应全部 `PASS` 且结尾 `VERIFIED`。不要将测试与大数据自检并行跑：此前曾观察到并行 MemoryError，原因尚未定位。

`.local/verification.json` 每次验证会更新，先把上一份报告另存，再执行下一轮；两项重算的详细目录写在报告中。测试退出不等于 GUI 通过，环境检查通过也不等于找到合格航迹。

合法新 `latest` 与缓存目录衔接仍存在已复现问题，详见[风险与限制](风险与限制.md)。它没有在本轮校验修复或文档收口中被标为解决。
