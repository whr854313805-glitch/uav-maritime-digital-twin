## 接收人怎样复跑

按 [README 命令](../../README.md#检查与重算)串行执行：环境检查 → 68测试 → 9基础 → M2/相向重算。每条退出码应为0；测试应为 `OK`，数据/重算应全部 `PASS` 且结尾 `VERIFIED`。不要将测试与大数据自检并行跑：此前曾观察到并行 MemoryError，原因尚未定位。

`.local/verification.json` 每次验证会更新，先把上一份报告另存，再执行下一轮；两项重算的详细目录写在报告中。测试退出不等于 GUI 通过，环境检查通过也不等于找到合格航迹。

## 仍未证明

组员实体机完整 GUI/GPU/安全软件兼容性；最终发布版全部10个可重算入口的新算；90 m/30 m/120 s等数值边界完整组合；长时/反复切换重算与资源峰值；每个故障中断点；第二台实体设备入站检查；极长目录可用性。已有实测和自动化均不能扩展为这些结论。

新结果与目录不同步的问题已修：16项新增测试覆盖连续/并发发布、坏结果拒绝、写盘中断恢复、无变化不重写、CLI错误和临时文件清理；实际AnyLogic中两次真实M2新算发布后，当前结果均自动重载且9项自检通过。见[发布闭环记录](../F28/native-publication.json)。这不代替其余未测项目。
